| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| cluster-admin |	Полный доступ ко всем ресурсам кластера	Системные администраторы, DevOps-инженеры |
| namespace-admin |	Полный доступ ко всем ресурсам в назначенных namespace | Руководители продуктовых команд, ведущие разработчики	|
| developer | Создание, изменение, удаление deployment, pods, services в назначенных namespace | Разработчики продуктовых команд	|
| viewer |	Только чтение всех ресурсов в назначенных namespace | Бизнес-аналитики, менеджеры, собственники (для мониторинга)	|
| auditor |	Чтение всех ресурсов + чтение секретов (для аудита безопасности)  | Специалист по ИБ, аудиторы	|
| ci-cd-bot |	Создание, изменение deployment, pods, services; чтение секретов | CI/CD системы |
